# RSMS Feedback Filler Extension

This is a browser extension for automating the RSMS feedback filling process.

## How to Install and Use

To use this extension, follow these simple steps to load it into your browser as an "Unpacked Extension".

### Prerequisites
- A Chromium-based browser like Google Chrome, Microsoft Edge, or Brave.

### Installation Steps
1. **Clone or Download the Repository:**
   - Clone the repo using git: 
     ```bash
     git clone https://github.com/ZAK1504/RSMS-FeedBACK-FILLER.git
     ```
   - OR click on the **Code** button on GitHub and select **Download ZIP**. Extract the downloaded ZIP file to a folder on your computer.

2. **Open the Extensions Page:**
   - In Chrome, type `chrome://extensions/` in your address bar and press Enter.
   - In Edge, type `edge://extensions/` and press Enter.

3. **Enable Developer Mode:**
   - On the Extensions page, look for the **Developer mode** toggle (usually in the top right corner) and turn it ON.

4. **Load the Extension:**
   - Click on the **Load unpacked** button that appears after enabling Developer mode.
   - Browse to the folder where you cloned or extracted the repository (the folder containing the `manifest.json` file) and select it.

5. **Pin the Extension:**
   - You should now see the extension installed in your browser.
   - Click the "puzzle piece" (Extensions) icon in your browser toolbar and pin the extension so it's easily accessible.

### Usage
- Navigate to the RSMS feedback portal.
- Click on the extension icon in your toolbar and use the popup interface to automate your tasks!
